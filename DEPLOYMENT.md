# Deployment

Public responsive prototype: https://finn-investor-brief-27.unknownmessiah49.chatgpt.site/?v=4c60891#portfolio

The latest deployed application source is Sites commit `4c60891f7533d142648411024bce2ca7b4e970de`. Native deployment reported succeeded and access was explicitly changed to public. The source in this GitHub repository is prepared from that application snapshot with updated submission documentation. It does not include the original Sites hosting identity.

Open on a phone or desktop. Scenario replay works without a paid key. Live provider coverage can vary; gaps remain visible. Browser notification behavior is foreground-only. WhatsApp is a non-delivering preference demo.

For local development use `npm install --omit=optional` and `npm start` with Node.js 22 or newer. For the downloaded prebuilt package use the root `run-finn.mjs` launcher. No account credentials or API keys are included.
